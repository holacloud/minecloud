# Mesas

![Mesa](item:table)

| | Nombre en el juego | Id | Se hace con |
|---|---|---|---|
| ![](item:table) | Table | `table` | 4 tablas de roble |
| ![](item:bedside_table) | Bedside Table | `bedside_table` | 3 tablas de roble, 1 mineral de hierro |
| ![](item:desk) | Desk | `desk` | 5 tablas de roble, 1 mineral de hierro |

Las mesas **se unen**: junta varias y se hacen un solo tablero, con patas solo en las esquinas de fuera. Alárgala para un banquete o hazla cuadrada para una reunión.

La parte de arriba de estas piezas llega hasta el borde de su celda, así que una [vela o una lámpara de mesa](228), una [maceta o un jarrón](231) puestos encima descansan justo sobre ella.

Los cajones de la mesilla y del escritorio solo están pintados: para guardar cosas, usa un [cofre](226).
