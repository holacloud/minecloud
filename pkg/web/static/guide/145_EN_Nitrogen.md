![Nitrogen block](item:element_n)

Element number **7** of the periodic table.

| | |
|---|---|
| Symbol | **N** |
| Atomic number | 7 |
| Group | 15 |
| Period | 2 |
| Family | nonmetal |
| In-game name | Nitrogen Block |
| Id | `element_n` |

## How to get it

Like every [element block](60), it is synthesised with the C key (*Synthesize N Block*):

| Result | Ingredients |
|---|---|
| 1 `element_n` | 1 `stone` + 1 `coal_ore` |

Each block is **one atom** at the [lab bench](117).

## In the lab

It takes part in **1** reaction you have to discover by mixing in the flask. Hints:

- *A nitrogen surrounded by hydrogens smells strong... and plants love it.*

## In the real world

- It makes up almost **78 %** of the air you breathe.
- Liquid nitrogen boils at −196 °C: it freezes a flower instantly.
- It is part of DNA and of every protein.
