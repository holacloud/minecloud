# Gold (Au)

![Gold block](item:element_au)

Element number **79** of the periodic table.

| | |
|---|---|
| Symbol | **Au** |
| Atomic number | 79 |
| Group | 11 |
| Period | 6 |
| Family | transition metal |
| In-game name | Gold Element Block |
| Id | `element_au` |

## How to get it

Like every [element block](60), it is synthesised with the C key (*Synthesize AU Block*):

| Result | Ingredients |
|---|---|
| 1 `element_au` | 1 `stone` + 1 `coal_ore` |

Each block is **one atom** at the [lab bench](117).

The ore, `gold_ore`, is [found in the world](248), and is another item: the [foundry](235) turns it into `gold_block`, not into this block.

## In the lab

It takes part in **1** reaction you have to discover by mixing in the flask. Hints:

- *Gold reacts with nothing, but alone in the flask it is beaten paper-thin.*

## In the real world

- It **never tarnishes**: the gold of ancient tombs shines like new.
- It is so malleable that a single gram covers half a square metre as gold leaf.
- All the gold ever mined would fit in a cube about 22 m on a side. Its symbol comes from the Latin *aurum*.
