# Calcium (Ca)

![Calcium block](item:element_ca)

Element number **20** of the periodic table.

| | |
|---|---|
| Symbol | **Ca** |
| Atomic number | 20 |
| Group | 2 |
| Period | 4 |
| Family | alkaline earth metal |
| In-game name | Calcium Block |
| Id | `element_ca` |

## How to get it

Like every [element block](60), it is synthesised with the C key (*Synthesize CA Block*):

| Result | Ingredients |
|---|---|
| 1 `element_ca` | 1 `stone` + 1 `coal_ore` |

Each block is **one atom** at the [lab bench](117).

## In the lab

It takes part in **3** reactions you have to discover by mixing in the flask. Hints:

- *Shells and chalk hold calcium, carbon and plenty of oxygen.*
- *One calcium with a single oxygen: the builders' lime.*
- *One calcium with two fluorines makes purple crystals.*

## In the real world

- It is the **most abundant metal in your body**: it is in bones and teeth.
- Limestone, marble and chalk are calcium carbonate.
