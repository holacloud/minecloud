# Estaño (Sn)

![Bloque de estaño](item:element_sn)

El elemento número **50** de la tabla periódica.

| | |
|---|---|
| Símbolo | **Sn** |
| Número atómico | 50 |
| Grupo | 14 |
| Periodo | 5 |
| Familia | otro metal |
| Nombre en el juego | Tin Block |
| Id | `element_sn` |

## Cómo conseguirlo

Como todos los [bloques de elementos](60), se sintetiza con la tecla C (*Synthesize SN Block*):

| Resultado | Ingredientes |
|---|---|
| 1 `element_sn` | 1 `stone` + 1 `coal_ore` |

Cada bloque es **un átomo** en la [mesa de laboratorio](117).

## En el laboratorio

Participa en **1** reacción que hay que descubrir mezclando en el matraz. Pistas:

- *Hace 5000 años alguien fundió mucho cobre con un poco de estaño...*

## En el mundo real

- Las «latas» son de acero cubierto de una capa de estaño.
- Con cobre forma el **bronce**.
- Si doblas una barra de estaño, cruje: es el «grito del estaño».
