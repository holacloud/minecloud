# Nickel (Ni)

![Nickel block](item:element_ni)

Element number **28** of the periodic table.

| | |
|---|---|
| Symbol | **Ni** |
| Atomic number | 28 |
| Group | 10 |
| Period | 4 |
| Family | transition metal |
| In-game name | Nickel Block |
| Id | `element_ni` |

## How to get it

Like every [element block](60), it is synthesised with the C key (*Synthesize NI Block*):

| Result | Ingredients |
|---|---|
| 1 `element_ni` | 1 `stone` + 1 `coal_ore` |

Each block is **one atom** at the [lab bench](117).

## In the lab

It takes part in **1** reaction you have to discover by mixing in the flask. Hints:

- *Iron that falls from the sky brings nickel: one and one.*

## In the real world

- Many **meteorites** are made of iron and nickel.
- In the United States the five-cent coin is called a *nickel*, though it is mostly copper.
- Its name comes from the German *Kupfernickel*, "copper devil".
