# Titanium (Ti)

![Titanium block](item:element_ti)

Element number **22** of the periodic table.

| | |
|---|---|
| Symbol | **Ti** |
| Atomic number | 22 |
| Group | 4 |
| Period | 4 |
| Family | transition metal |
| In-game name | Titanium Block |
| Id | `element_ti` |

## How to get it

Like every [element block](60), it is synthesised with the C key (*Synthesize TI Block*):

| Result | Ingredients |
|---|---|
| 1 `element_ti` | 1 `stone` + 1 `coal_ore` |

Each block is **one atom** at the [lab bench](117).

## In the lab

It takes part in **2** reactions you have to discover by mixing in the flask. Hints:

- *Painters' whitest white comes from titanium hugging two oxygens.*
- *The same corundum turns blue with a little iron and titanium.*

## In the real world

- It is as **strong** as steel, but much lighter.
- It is used in aircraft, racing bikes and hip implants, because the body tolerates it well.
- It is named after the Titans of Greek mythology.
