# Beryllium (Be)

![Beryllium block](item:element_be)

Element number **4** of the periodic table.

| | |
|---|---|
| Symbol | **Be** |
| Atomic number | 4 |
| Group | 2 |
| Period | 2 |
| Family | alkaline earth metal |
| In-game name | Beryllium Block |
| Id | `element_be` |

## How to get it

Like every [element block](60), it is synthesised with the C key (*Synthesize BE Block*):

| Result | Ingredients |
|---|---|
| 1 `element_be` | 1 `stone` + 1 `coal_ore` |

Each block is **one atom** at the [lab bench](117).

## In the lab

It does not react with anything in the lab yet: for now it is a building block... or maybe someone will discover something with it in a future version?

## In the real world

- It is light and very stiff: the mirrors of the **James Webb** space telescope are beryllium coated with gold.
- **Emeralds** and aquamarines are kinds of beryl, a beryllium mineral.
