![Platinum block](item:element_pt)

Element number **78** of the periodic table.

| | |
|---|---|
| Symbol | **Pt** |
| Atomic number | 78 |
| Group | 10 |
| Period | 6 |
| Family | transition metal |
| In-game name | Platinum Block |
| Id | `element_pt` |

## How to get it

Like every [element block](60), it is synthesised with the C key (*Synthesize PT Block*):

| Result | Ingredients |
|---|---|
| 1 `element_pt` | 1 `stone` + 1 `coal_ore` |

Each block is **one atom** at the [lab bench](117).

## In the lab

It does not react with anything in the lab yet: for now it is a building block... or maybe someone will discover something with it in a future version?

## In the real world

- It does not tarnish and it is very dense.
- Car **catalytic converters** use platinum to clean exhaust gases.
- The Spanish called it *platina*, "little silver". Until 2019 the standard kilogram was a cylinder of platinum and iridium.
