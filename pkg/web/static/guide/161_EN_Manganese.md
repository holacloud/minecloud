# Manganese (Mn)

![Manganese block](item:element_mn)

Element number **25** of the periodic table.

| | |
|---|---|
| Symbol | **Mn** |
| Atomic number | 25 |
| Group | 7 |
| Period | 4 |
| Family | transition metal |
| In-game name | Manganese Block |
| Id | `element_mn` |

## How to get it

Like every [element block](60), it is synthesised with the C key (*Synthesize MN Block*):

| Result | Ingredients |
|---|---|
| 1 `element_mn` | 1 `stone` + 1 `coal_ore` |

Each block is **one atom** at the [lab bench](117).

## In the lab

It does not react with anything in the lab yet: for now it is a building block... or maybe someone will discover something with it in a future version?

## In the real world

- Almost all the manganese mined is used to make **steel**.
- It is in alkaline batteries, as manganese dioxide.
- The ocean floor is covered in millions of potato-sized "nodules" rich in manganese.
