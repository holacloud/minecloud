| | |
|---|---|
| Symbol | **Ne** |

| Group | 18 |
| Period | 2 |
| Family | noble gas |
| In-game name | Neon Block |
| Id | `element_ne` |

## How to get it

Like every [element block](60), it is synthesised with the C key (*Synthesize NE Block*):

| Result | Ingredients |
|---|---|
| 1 `element_ne` | 1 `stone` + 1 `coal_ore` |

Each block is **one atom** at the [lab bench](117).

## In the lab

It takes part in **1** reaction you have to discover by mixing in the flask. Hints:

- *Alone, inside some glass, it glows red-orange.*

## In the real world

- With electricity it glows an unmistakable **red-orange**.
- William Ramsay and Morris Travers discovered it in London in **1898**; *neos* means "new".
- It is very scarce in the air: about 18 parts per million.
