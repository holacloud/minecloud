# Tables

![Table](item:table)

| | In-game name | Id | Made from |
|---|---|---|---|
| ![](item:table) | Table | `table` | 4 oak planks |
| ![](item:bedside_table) | Bedside Table | `bedside_table` | 3 oak planks, 1 iron ore |
| ![](item:desk) | Desk | `desk` | 5 oak planks, 1 iron ore |

Tables **join**: put several together and they become one big top, with legs only at the outer corners. Make it long for a banquet or square for a meeting.

The top of each of these pieces is level with the top of its cell, so a [candle or a table lamp](228), a [flower pot or a vase](231) placed on top rests right on it.

The drawers of the bedside table and the desk are only painted: to keep things, use a [chest](226).
