# Comandos del chat

Pulsa **Enter** para abrir el chat, escribe y pulsa **Enter** otra vez para enviar. **Escape** lo cierra
sin enviar.

Lo que empieza por **/** es un comando: no lo ven los demás, lo ejecuta el juego.

## Todos los comandos

| Comando | Qué hace |
|---|---|
| `/help` | muestra la lista de comandos |
| `/guide` | abre esta guía donde la dejaste |
| `/guide 12` | abre la guía por la página 12 (también vale un código secreto) |
| `/spawn` | te lleva a tu punto de reaparición: tu cama o, si no tienes, el último sitio seguro |
| `/mob horse` | hace aparecer un animal delante de ti (ver abajo) |
| `/time` | dice la hora del mundo, por ejemplo "21:30" |
| `/rtx` | activa o desactiva el modo RTX (ver [Modos gráficos](14)) |
| `/sayhere texto` | deja un mensaje flotando en tu sitio durante 30 s (hasta 80 letras) |
| `/ping` | levanta un rayo de luz con tu nombre en tu sitio durante 10 s |
| `/react heart` | lanza corazones sobre el jugador al que apuntas |
| `/react clap` | aplausos sobre el jugador al que apuntas |
| `/react confetti` | confeti sobre el jugador al que apuntas |
| `/laugh` | una risa que oyen los que están cerca |
| `/cheer` | un vítor que oyen los que están cerca |
| `/boo` | un abucheo que oyen los que están cerca |

- `/sayhere`, `/ping` y `/react` los ven **todos los jugadores**.
- Para `/react` tienes que apuntar a un jugador a menos de 7 bloques.
- `/laugh`, `/cheer` y `/boo` se oyen hasta unos 16 bloques, más fuerte cuanto más cerca.

## Mencionar a alguien

Haz **clic izquierdo** sobre otro jugador: se abre el chat con `@nombre` ya escrito.
