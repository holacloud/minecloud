Element number **12** of the periodic table.

| | |
|---|---|
| Symbol | **Mg** |
| Atomic number | 12 |
| Group | 2 |
| Period | 3 |
| Family | alkaline earth metal |
| In-game name | Magnesium Block |
| Id | `element_mg` |

## How to get it

Like every [element block](60), it is synthesised with the C key (*Synthesize MG Block*):

| Result | Ingredients |
|---|---|
| 1 `element_mg` | 1 `stone` + 1 `coal_ore` |

Each block is **one atom** at the [lab bench](117).

## In the lab

It does not react with anything in the lab yet: for now it is a building block... or maybe someone will discover something with it in a future version?

## In the real world

- It burns with a **blinding white** light: it was used in the flashes of early photography.
- At the centre of every **chlorophyll** molecule, which makes plants green, there is a magnesium atom.
- Its light alloys are used in bicycles and laptops.
