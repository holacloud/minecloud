Element number **80** of the periodic table.

| | |
|---|---|
| Symbol | **Hg** |
| Atomic number | 80 |
| Group | 12 |
| Period | 6 |
| Family | transition metal |
| In-game name | Mercury Block |
| Id | `element_hg` |

## How to get it

Like every [element block](60), it is synthesised with the C key (*Synthesize HG Block*):

| Result | Ingredients |
|---|---|
| 1 `element_hg` | 1 `stone` + 1 `coal_ore` |

Each block is **one atom** at the [lab bench](117).

## In the lab

It takes part in **1** reaction you have to discover by mixing in the flask. Hints:

- *Argon with a drop of the liquid metal, in glass, glows blue.*

## In the real world

- It is the only metal that is **liquid** at room temperature.
- It was used in old thermometers. It is toxic: never touch it.
- Its symbol comes from *hydrargyrum*, "liquid silver".
