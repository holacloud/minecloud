# MineCloud Expansion Microtasks

## 1. Block Catalog
- [ ] Define a broad catalog of new blocks: colored bricks, woods, colored wool, slabs, materials, and periodic table elements.
- [ ] Add block definitions and visual colors to the renderer.
- [ ] Add all new placeable blocks to inventory/crafting availability.
- [ ] Add recipes for new blocks to the crafting UI.
- [ ] Verify crafting search/detail works with the expanded catalog.

## 2. Tools
- [ ] Define tool items: swords, shovels, pickaxes, axes, hoes, and shears across material tiers.
- [ ] Add tool items to inventory display and crafting.
- [ ] Implement tool effectiveness by block category.
- [ ] Verify block mining speed improves over bare hands.

## 3. Animal Eggs
- [ ] Identify all current animal species.
- [ ] Add one spawn egg item per animal.
- [ ] Make eggs discoverable in the world as pickups.
- [ ] Allow using eggs to spawn animals.

## 4. Trees And Seeds
- [ ] Add more wood and leaf block variants.
- [ ] Add sapling/seed items for tree types.
- [ ] Generate more tree variants in world chunks.
- [ ] Allow planting seeds/saplings.

## 5. Verification
- [ ] Run available automated checks.
- [ ] Smoke-test crafting, mining, placement, eggs, and tree generation manually where possible.
- [ ] Commit each relevant completed milestone.
